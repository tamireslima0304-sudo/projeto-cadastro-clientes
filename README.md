Projeto Cadastro de Clientes

Sobre o Projeto
Este é um projeto desenvolvido em Python para praticar conceitos de programação e gerenciamento de configuração de software.
O sistema permite cadastrar clientes, listar os clientes cadastrados e encerrar o programa.

Funcionalidades
*Cadastrar clientes com nome, telefone e e-mail.
*Listar os clientes cadastrados.
*Exibir uma mensagem de configuração após o cadastro.
*Encerrar o programa pelo menu.

Tecnologias utilizadas
*Python
*Git
*GitHub
*Visual Studio Code

Como Executar
1. Faça p Download ou clone deste repositorio.
2. Abra a pasta do Projeto no Visual Studio Code.
3. Execute o arquivo cadastro.py
